# ポスター制作ガイド（CLIエージェント向け）

このフォルダは **1件のポスター制作プロジェクト**です．`poster_template` から生成されました．

## 0. 最初に必ず読む

- `poster_spec.md` — 制作仕様書．**§3（固定項目）と §4-5（HTML禁止事項）は絶対に破らない．**
- `content.md` — 流し込む素材（論文要点・実験数値・図リスト）の記入シート．

## 1. 変更してよいのはこの4項目だけ（spec §2）

| 項目 | 変更箇所 |
|---|---|
| サイズ・向き | `:root` の `--poster-w` / `--poster-h` と `@page size` の2箇所（JSは自動追従） |
| 段組み | カード内の `.cols-*` のみ．本文全体は1段組み固定 |
| カラー | `--col-primary` / `--col-secondary` の2変数のみ |
| 本文の中身 | `poster.html` の `<body>` 内テキスト・図・数値 |

それ以外（フォント・フォントサイズ・余白・角丸・配置・罫線）は**固定**．触らない．

## 2. HTMLでやってはいけないこと（spec §4-5）

- `font-size` の数値直書き → `var(--fs-*)` 経由のみ
- `color` の直書き → `var(--col-*)` 経由のみ
- `border-radius` の直書き → `var(--r-*)` か `0` のみ
- `font-family` の直書き → `var(--font-*)` 経由のみ
- `text-align:center` の追加 → 禁止（中央揃えは `.n/.mv/.ml/.fc/.pf-fund` のみ，CSSで定義済み）

これらは `node tools/lint.mjs` が機械的に検出する．

## 3. 制作ワークフロー（この順で回す）

```
1. content.md に素材を集約する（論文から抜き出す・数値を確定する）
2. poster.html の <body> に流し込む（セクション構造は spec §4-2 を踏襲）
3. node tools/lint.mjs        ← 仕様違反チェック（エラー0になるまで直す）
4. node tools/render.mjs      ← out/poster.pdf と out/poster.png を生成
5. out/poster.pdf が「1ページ」か確認（render が PDF ページ数で警告する）
   → 2ページ以上＝溢れ．分量を削る／図を縮小する
6. out/poster.png を Read して見た目を目視確認 → 2 に戻って反復
```

**lint と render の両方が通るまでが1サイクル．** コミットは区切りの良い単位で．

## 4. 図の扱い

- 画像は `figures/` に置く．ファイル名は内容がわかる英小文字（例 `fig1_paradigm.png`）．
- A0印刷を想定し，**実寸で 300dpi 相当**になる解像度を確保する（グラフは可能なら SVG）．
- プレースホルダーから実画像への差し替えは spec §4-4 の `.fig-wrap` 形式を使う．

## 5. 分量の目安（溢れ防止）

A0縦1枚・6セクションが基準．迷ったら削る方向で．

| セクション | 本文の目安 | 図 |
|---|---|---|
| 背景 | 3〜5行＋強調1 | 0〜1 |
| 目的・仮説 | 箇条書き3＋仮説1 | 0 |
| 手法 | 箇条書き4〜6 | 1 |
| 結果 | 指標カード3〜4＋本文3行 | 1〜2（主役） |
| 考察 | 強調1＋箇条書き3〜4 | 0 |
| 結論＋参考文献 | 結論3＋文献3〜6 | 0 |

「結果」を主役に，図は大きく．他は文字を絞る．

## 6. プレースホルダー対応表（厳守）

**テンプレのHTML構造・要素の配置は一切変更しない．**
各プレースホルダーのテキストを `content.md` の値で上書きするだけ．
要素の追加・削除・移動・クラス変更はすべて禁止．

### ヘッダー（`.ph`）

| HTML要素 | クラス | 流し込む内容 | 禁止事項 |
|---|---|---|---|
| `<h1>` | `ph-title` | 論文タイトル（改行は `<br>` のみ） | 要素の移動・削除 |
| `<span>` | `ph-tag ac` | **学会・シンポジウムの正式名称のみ**（例：「ヒューマンインタフェースシンポジウム 2026」） | 別の情報（著者・日付）を混入させない |
| `<span>` | `ph-tag`（1つ目） | **発表番号のみ**（例：「PS-12」「OS-03」） | 学会名・日付を入れない |
| `<span>` | `ph-tag`（2つ目） | **発表年月・会場のみ**（例：「2026年9月　東京都」） | 学会名・発表番号を入れない |
| `<p>` | `ph-authors` | 著者名の列記（上付き数字で所属対応） | 所属・学会名の混入 |
| `<p>` | `ph-affil` | 所属機関名（行ごとに `<br>` 区切り） | 著者名・連絡先の混入 |

**`ph-tags` の `<span>` は3つ固定．** 増やすと右カラムが崩れる．学会名・番号・日時以外の情報（キーワード等）を追加したいときも `ph-tags` には入れない．

### フッター（`.pf`）

| HTML要素 | クラス | 流し込む内容 | 省略時の処理 |
|---|---|---|---|
| `<div>` | `pf-qr` | QRコードの `<img>` タグ（なければ `hidden` クラスを追加） | `class="pf-qr hidden"` にする |
| `<div>` | `pf-contact` | 連絡先著者の氏名・メール・URL | 省略不可 |
| `<div>` | `pf-fund` | 助成・謝辞（なければ `hidden` クラスを追加） | `class="pf-fund hidden"` にする |

`hidden` クラスの付け方：`<div class="pf-qr hidden">` — これ以外の非表示方法（`display:none` 直書き，要素削除）は使わない．

### 本文セクション（`.sc`）

- `.sc-title` 内の `.n`（番号円）と見出しテキストは **番号・タイトル名ともに変更してよい**が，`.n` 要素自体は削除しない．
- 各 `.sc` に含まれる `.fig`（プレースホルダー図）は，実画像が用意できた時点で `.fig-wrap` + `<img>` 形式に差し替える（spec §4-4）．用意できない場合はそのまま残す（削除禁止）．
- `.hbox` / `.hbox-primary` は強調ボックスとして用途が決まっている（`.hbox`：考察メッセージ，`.hbox-primary`：仮説）．内容だけ書き換え，要素ごと削除・別の場所へ移動しない．

## 7. 配色プリセット（spec §2-3）

```css
/* HI学会（デフォルト） */ --col-primary:#502F8E; --col-secondary:#F97213;
/* 認知科学会 */          --col-primary:#E8600A; --col-secondary:#502F8E;
```

補助色（`--col-red/blue/yellow/teal`）は図中の色分け専用．テンプレ構造には使わない．
