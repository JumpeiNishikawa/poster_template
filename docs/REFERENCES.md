# References

## Earlier Poster Project Lessons

- Prefer project-local `AGENTS.md` plus docs memory for handoff.
- Use compact condition tables instead of stacked condition cards when result sections threaten A0 overflow.
- Keep explanatory notes as plain `p.sub` lines when card-like styling adds visual weight without adding structure.
- Treat layout compression values such as reduced `line-height` and `--gap-block` as final-fit exceptions, not as template defaults.
- Keep concept figures editable in HTML/CSS when the figure is part of final layout tuning.
